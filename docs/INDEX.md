# Rate-Sentinel Documentation Index

This folder contains the authoritative markdown documentation for the project.
It is intentionally markdown-only; no PDF generation is used in the current workflow.

## Core Project Documents

| File | Purpose |
|---|---|
| `HLD.md` | High-level design: architecture, runtime flows, deployment, and frontend overview |
| `LLD.md` | Low-level design: module responsibilities, implementation details, and frontend design |
| `BRD.md` | Business requirements: stakeholder needs, goals, KPIs, and business scope |
| `PRD.md` | Product requirements: APIs, functional requirements, data models, and non-functional expectations |
| `API_SPECS.md` | API contracts, request/response formats, headers, and security behavior |

## Frontend Documentation

## What to Read First

1. `README.md` at project root for an overall project summary.
2. `docs/HLD.md` for system architecture and flow overview.
3. `docs/LLD.md` for implementation-level detail.
4. `docs/API_SPECS.md` for endpoint contracts.
5. `frontend/README.md` for UI-specific details.

- Markdown files are kept as the source of truth so they can be edited and versioned easily.
